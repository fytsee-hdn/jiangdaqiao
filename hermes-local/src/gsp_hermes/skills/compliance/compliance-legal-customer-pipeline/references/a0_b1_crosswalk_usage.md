# A0/B1 Crosswalk Usage

Status: `LIVE_POINTER_ONLY`

Use the live knowledge-base catalog JSON to resolve the current canonical legal
metadata database, current crosswalk entry, and current active classification
table/view. Do not use this reference for hardcoded table names, counts, or
priority versions.

Allowed use: identity review, VBPL-missing monitor review, status-conflict
triage, and official-text acquisition planning.

Blocked use: treating third-party B1 rows as official law, auto-merging
ambiguous records, legal advice, compliance conclusions, checklist generation,
requirement atoms, risk ratings, audit-pass claims, or confirmed baseline.
